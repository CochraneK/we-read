### 坑：Windows 保留设备名文件 nul 删不掉
- `nul`（46B）是误生成的垃圾，但 Windows 把 `nul` 当空设备名，普通 `rm`/`del`/Python `os.remove` 均被 safe-delete 拦截并报「设备名无效」
- 最终用 `ctypes.windll.kernel32.DeleteFileW(r"\\?\D:\...\nul")` 直接调 Win32 API + `\\?\` 前缀绕过设备名解析，成功删除
- 经验：删 Windows 设备名文件（nul/con/aux 等）要用 `\\?\` 长路径前缀 + 直接 API 调用，绕过 safe-delete 钩子
