三分钟跑起来

建议把真实数据放在仓库外部。页面和仓库示例都不需要你的 API Key。

# 1. 数据放仓库外
export WEREAD_DATA_DIR="$HOME/.local/share/we-read"
export WEREAD_API_KEY="wrk-..."

# 2. 拉取并建立事实层
python scripts/export_notes.py
python scripts/fetch_enrich.py
python scripts/build_visualization_context.py

# 3. 立即可用的确定性能力
python scripts/renderers/heatmap.py
python scripts/build_search_index.py --rebuild
python scripts/build_recall_queue.py

# 4. 汇总报告
python scripts/renderers/report.py

本地优先，不拿隐私换漂亮图。

阅读记录可以透露非常私人的兴趣与想法，因此安全边界是产品功能的一部分，而不是 README 最后一段。

默认做什么

  • 明确 secret=1 的书默认排除
  • API Key 不写入产物和日志
  • 搜索索引和生成报告默认 gitignore
  • 仓库内 fallback preview 使用合成数据；线上 Page 按 publication policy 生成
  • AI 解释保留 evidence / counterEvidence

默认不做什么

  • 不自动公开你的划线和想法
  • 不把书架等同于“读过”
  • 不从阅读记录推断敏感属性
  • 不让同步程序覆盖 Obsidian 手写区
  • 不把启发式版权判断当法律结论
