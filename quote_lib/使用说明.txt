名言卡片 · 交付包使用说明

【三套风格切换】
用浏览器打开 cards.html，点击页面顶部工具栏的 A / B / C 按钮，即可在三种风格间实时切换：
  A = 暖米色 · 极简（陶土暖调，书卷气）
  B = 墨色 · 留白（古典衬线，沉淀感最强）
  C = 杂志风 · 暗夜（深底浅字，社媒传播最跳）

【强调色高亮】
每张卡片的署名破折号「—」与书名《》已自动染上当前主题的强调色（A 陶土橙 / B 深棕褐 / C 朱砂），
让"谁说的、出自哪本书"一眼可辨，作者名保持次级灰、不抢戏。这是刻意的高亮处理，不影响正文对比度。

【导出实体卡片集（PDF）】
1. 浏览器打开 cards.html；
2. 按 Ctrl/Cmd + P 调出打印（打印时工具栏自动隐藏）；
3. 目标选择「另存为 PDF」，勾选「背景图形」；
4. 保存即得 351 张实体卡片集（A4 两列排版），可打印收藏。

【文件清单】
  cards.html        —— 351 张名言卡片（3 主题 / 打印 CSS / 离线单文件）
  金句库.json       —— 金句数据源（351 条，含作者/书名/主题/分级）
  金句库_top60.md   —— 精选 Top 60 清单，便于快速浏览
  design-tokens.md  —— 三套主题设计令牌规范（色值/字号/对比度）
