# 名言警句小卡片 · 设计令牌文档

> 基准画布 1080×1350（竖版社媒），预留 3:4 实体书 / 4:5 明信片适配。
> 25 条 tier-A 真实名句，正文 17–64 字（均 37）。署名固定「— {author}《{title}》」。
> **对比度自测：所有正文 ≥4.5:1（AA），署名/书名 ≥3:1，强调色（图形/标签）≥3:1；无纯黑 #000，无 AI 紫 #B279A2。**

---

## 方案 A — 暖中性延续（Soft Warm，与年报同源）
**视觉**：米白纸感 + 陶土强调，柔和克制，最贴"书卷气/不炫技"。

| 项 | 令牌 | 值 |
|---|---|---|
| 画布/卡底 | --bg | #FBF8F3（多比例同底，仅边距缩放） |
| 引言正文 | --quote | #43342B，11.2:1 |
| 署名行 | --attr | #6B5A4D，6.2:1 |
| 书名小字 | --title | #8A7B6E，3.9:1 |
| 强调色 | --accent | #C2724B（破折号/分隔线/标签），3.4:1 |

- **字体**：引言=思源宋体/Source Han Serif/Noto Serif SC/系统宋体/serif（衬线，人文）；署名/书名=同族 Regular 或 苹方/PingFang SC/system-ui 降一级。
- **字号(1080×1350)**：引言 48–64px，按长度 短(≤20字)64 / 中(21–40)56 / 长(41–64)48；行高 1.6；字重 500–600；**换行**每行≤16字，自动按标点断行，最多 5 行，超出启用 48px 兜底。
- **署名**：字号 30px，字重 500，与引言间距 40px；书名 22px、字重 400、与署名间距 8px。
- **主题标签**：pill 描边（1.5px --accent），文字 20px --accent，圆角 999px，置于署名下方 24px。
- **留白**：内边距 96px（安全区顶/底 120、左右 96）；内容垂直居中偏上。
- **适配**：明信片 4:5 → 边距 84；实体书 3:4 → 边距 72，字号×0.94。

---

## 方案 B — 古典衬线（Editorial Monocle，极简沉淀）
**视觉**：大号衬线 + 大量留白 + 极细分隔，人文最浓。

| 项 | 令牌 | 值 |
|---|---|---|
| 画布/卡底 | --bg | #F6F3EC（暖象牙） |
| 引言正文 | --quote | #2B2622，13.5:1 |
| 署名行 | --attr | #5C534A，6.8:1 |
| 书名小字 | --title | #7A7066，4.4:1 |
| 强调色 | --accent | #8A5A3C（深棕褐，分隔/破折号），5.3:1 |

- **字体**：引言=思源宋体/Noto Serif SC/Source Han Serif/serif，字重 400（靠留白与字号显分量）；署名/书名=同族 400。
- **字号**：引言 56–72px（短 72 / 中 64 / 长 56），行高 1.7，字重 400；**换行**每行≤14字，最多 4 行。
- **署名**：32px / 400 / 间距 48px；书名 22px / 400 / 间距 8px。
- **主题标签**：纯文字 + 上方 1px --accent 细线（长 40px），文字 20px --accent，无框。
- **留白**：内边距 120px（大量留白），引言偏上 1/3，署名左下对齐。
- **适配**：明信片 4:5 → 边距 104；实体书 3:4 → 边距 92，字号×0.92。

---

## 方案 C — 杂志风（High-Contrast Editorial，锐利主张）
**视觉**：深底浅字强对比，编辑式排版，社媒最跳。

| 项 | 令牌 | 值 |
|---|---|---|
| 画布/卡底 | --bg | #1E1B18（暖近黑，非纯黑） |
| 引言正文 | --quote | #F2EDE4，14.7:1 |
| 署名行 | --attr | #B8A896，7.4:1 |
| 书名小字 | --title | #9A8D7E，5.3:1 |
| 强调色 | --accent | #CC4B2C（朱砂），3.8:1 |

- **字体**：引言=思源宋体/Noto Serif SC/serif（衬线，与深底形成编辑张力）；署名/书名=苹方/PingFang SC/system-ui（无衬线，对比质感）。
- **字号**：引言 52–68px（短 68 / 中 60 / 长 52），行高 1.5，字重 600；**换行**每行≤15字，最多 5 行。
- **署名**：30px / 500 / 间距 40px；书名 21px / 400 / 间距 8px。
- **主题标签**：实心 pill（--accent 底 + #F2EDE4 字，3.9:1），20px，圆角 999px，右上角对齐。
- **留白**：内边距 96px；引言左对齐，顶部留 88px 放细 accent 顶规。
- **适配**：明信片 4:5 → 边距 84；实体书 3:4 → 边距 76，字号×0.94。可切浅底深字版（#F4EFE6 底 / #1E1B18 字 / 同 accent）。

---

## 按主题微弱配色（8 主题，可选，低密度图形用）
仅作破折号点/左细规/标签描边，**不作为正文色**（保证对比）。低饱和、与各自底色调和：
人生 #C9A36B · 自我 #A98C6B · 情感 #C98B8B · 时间 #8FA3A8 · 苦难 #9A7B5C · 关系 #B08A6A · 社会 #8F9B7A · 认知 #7E93A0（避开紫调）。

## 推荐
- **最贴"人文/克制/书卷气" → 方案 B（古典衬线）**：大留白+衬线+极细线，沉淀感最强，最不炫技。
- **最适合社媒传播 → 方案 C（杂志风）**：深底浅字强对比，信息流中最跳，标签锐利有主张。
- **平衡之选/与年报同源 → 方案 A（暖中性）**：陶土暖调亲和，落地最稳，三平台统一成本低。
